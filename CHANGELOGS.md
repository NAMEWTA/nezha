# Nezha Plus Extension Features

This file only lists newly added extension features in Nezha Plus (`personal/extensions`). It does not list upstream Nezha release notes, bug fixes, refactors, dependency changes, tests, formatting, or routine maintenance.

## 2026-06-07

- Personal release handling: in-app release links resolve to `NAMEWTA/nezha` so Nezha Plus builds open the personal fork's release notes.
- Configurable navigation shortcuts: app settings can customize project switching, task switching, new task creation, and project switcher shortcuts.
- Rail attention animation: project rail can show a mascot wave animation when a task newly requests attention.
- Personal branch workflow helpers: repository-local branch preparation and tag validation scripts support the `personal/extensions` enhancement workflow.

## 2026-06-06

- Git file tree view: Git Changes and Git History can display changed files in a tree browser for easier review of large diffs.
